02 · The Intelligence Layer

Microsoft IQ

What makes agents genuinely useful is context. Microsoft IQ is the enterprise intelligence layer that gives every Copilot and agent a shared, always-current understanding of your organization.

It connects how people work, how the business operates, and how agents unlock knowledge — so intelligence is grounded, not guessed. Four interconnected capabilities · one intelligence layer
Work IQ — how people work
Fabric IQ — the state of the business
Foundry IQ — institutional knowledge
Web IQ — fresh intelligence from the web
↓ feeds every Copilot & agent interaction
IQ.01

Work IQ

User context

A live understanding of how people work — the context of people, collaboration, and workflows. Built on your data, memory, and inference across email, files, meetings, and chats, so Copilot can predict the next best action.

IQ.02

Fabric IQ

Data context

The live state of the business — so agents understand business entities and their relationships, properties, actions, and rules. It elevates raw data into the language of your business, grounded in a single source of truth.

IQ.03

Foundry IQ

Knowledge context

Curated institutional knowledge — policies, authoritative documents, and reusable knowledge bases in one managed system. It grounds agents over many sources so they cite their sources and reason with fewer mistakes.

IQ.04

Web IQ

World context

Fresh, real-world intelligence from across the web — giving AI systems and agents current context beyond the four walls of the organization, so decisions reflect what's happening right now.
